# youtube_pain_harvester

从多渠道自动收集客户痛点并生成YouTube视频选题的工具

## 功能
- 抓取Reddit/Facebook/Discord等社区的高频问题
- 分析YouTube评论区找内容空白点
- 从客户支持记录提取痛点关键词
- 生成SEO优化的视频标题和描述
- 追踪视频搜索排名和AI引用情况

## 安装
```bash
pip install -r requirements.txt
python src/main.py --help
```

## 技术栈
Python, requests/httpx, BeautifulSoup/Playwright, OpenAI API, YouTube Data API, SQLite
